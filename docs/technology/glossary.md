# Glossary

**Allocated capacity:** Telecommunications capacity assigned to a user, service or organisation.

**Consumption:** The measured amount actually used.

**DBU:** Data-Backed Unit; an internal accounting unit generated after verification.

**Givabit:** Urbyte's community value-routing layer.

**MNO:** Mobile network operator.

**MVNO:** Mobile virtual network operator.

**Proof of Waste:** Evidence establishing the difference between eligible allocation and consumption.

**Urbyte Insight:** Urbyte's enterprise analytics and verification platform.
